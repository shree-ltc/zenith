# Zenith Next.js Interactive Frontend

Engineered by **Shree** (`shree-ltc`, Discord ID `1465912900710305822`).

Built with **Next.js 16**, **React 19**, **Framer Motion 12**, and **Tailwind CSS**. Adheres strictly to **Taste Skill 2.5** and **Motion Design Principles** (Emil Kowalski speed & restraint, Jakub Krehel production polish).

## Components & Animated Effects
- `CyberGridPulse`: Hardware-accelerated canvas background with orthogonal signal traces and proximity glow.
- `SpotlightCard`: Mouse-tracking radial spotlight border and illumination.
- `InteractiveTerminal`: Live streaming telemetry terminal with state filters and auto-scroll.
- `InteractivePipeline`: Three-tier animated defense flow with interactive diagnostic telemetry inspector.
- `CommandMatrix`: Real-time instant search and category filtering across 504 command endpoints.

## Development & Build
```bash
# Development server
npm run dev

# Production static export build
npm run build
```
